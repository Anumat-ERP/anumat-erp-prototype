# Discover welcome animation

`workspace-folder.json` is a local color adaptation of **Document Folder**, by Leonard Rey Fernandez.

- Source: https://lottiefiles.com/free-animation/document-folder-UW57k7pmft
- Original public asset: https://assets-v2.lottiefiles.com/a/829c94b6-1153-11ee-b7e1-bb2c311193f3/z3mbh4TXU6.lottie
- Retrieved: 2 October 2026.
- License: Lottie Simple License; full terms in LICENSE.txt. The adapted animation retains these terms.
- Adaptation: red fills and folder faces replaced with mint, dark blue outlines with teal, background solid removed for transparency. Shape geometry/keyframes retained; the player uses frames 0–198 to settle in the open-folder pose. No embedded text, images, expressions or remote asset dependencies.

Discover loads the local JSON and SVG player on demand, plays once at 1.6× speed, and pauses when offscreen or the document is hidden. Reduced motion, static preview, or load failure keeps the existing workspace-folder.webp illustration. The animation is decorative; headings and navigation remain available immediately. No runtime LottieFiles/CDN requests are made.
