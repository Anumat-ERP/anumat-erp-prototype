# Anumat delivery planning

Confirmed audience: Cambodian small and medium businesses. Approach: complete the bounded prototype before production development, then sell a focused release and expand from customer evidence.

- [Development roadmap](../../DEVELOPMENT_ROADMAP.md): current gaps, eight prototype phases, seven production/commercial phases, dependencies, gates, estimates, risks and first sprint.
- [Implementation status](IMPLEMENTATION_STATUS.md): delivered workflows, verification evidence, demo instructions and remaining work.
- [Prototype backlog](PROTOTYPE_BACKLOG.md): shared foundation, all twelve apps, connected lifecycle, proposed tickets, fields/states and starting acceptance criteria.
- [Prototype acceptance](PROTOTYPE_ACCEPTANCE.md): evidence register, module acceptance matrix, four demo scripts, coverage strategy and G1/G2 checklists.
- [Storybook guide](../../STORYBOOK.md): current interactive UI catalogue and verification commands.

The backlog and acceptance matrix remain planning artifacts. Eight HR apps now have implemented local workflows; implementation does not imply every acceptance criterion or commercial gate has passed. Refer to the implementation status for actual evidence.
